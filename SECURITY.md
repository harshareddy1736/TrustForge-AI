# Security policy

## Supported scope

This repository is a local-first portfolio MVP. Please report reproducible security issues involving its source code, API validation, archive handling, secret redaction, dependency matching, or export generation.

## Reporting

Do not publish real credentials, private repository URLs, exploit payloads against systems you do not own, or sensitive personal data in an issue. For a private report, contact the repository maintainer through the contact method listed on their GitHub profile.

## Safe-use notes

- Only scan repositories you are authorized to assess.
- The current release supports public GitHub repository URLs only.
- Do not expose the local API or H2 console to the public internet.
- Findings are static-analysis/advisory indicators and require human validation.
