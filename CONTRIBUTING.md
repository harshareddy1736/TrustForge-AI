# Contributing

1. Open an issue describing the proposed change or bug.
2. Keep pull requests focused and include tests for behavior changes.
3. Do not add real credentials, local databases, virtual environments, or generated build directories.
4. Run Python tests, Maven verification with Java 25, and frontend tests/build before submitting.
5. Document new detectors, their severity rationale, false-positive considerations, and any new external data sources.
6. Never execute downloaded repository code as part of scanning.
